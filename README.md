# DIREC Project: Robust Network Intrusion Detection

This Hugo site presents the DIREC project and four paid student project themes:

1. **Building datasets for training robust network intrusion detection classifiers based on neural networks**
2. **Training with secure multiparty computation and differentiable logics**
3. **Building rules for training with properties network intrusion classifiers**
4. **Extending the differentiable logics approach for training and verification**

Each section provides details and opportunities for student involvement.

## Getting Started

- To run the site locally: `hugo server -D`
- Edit content in the `content/` directory.
- Customize the theme as needed.
